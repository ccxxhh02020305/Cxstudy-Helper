# Cxstudy-Helper
“学习不通”  A script that helps college students easily and quickly complete assignments for online courses

目前已实现自动刷PPT以及课程视频。最新加入了解题功能，不过目前非常不稳定，我加入了开启按钮，各位可以自行决定是否开启。

<img width="620" height="183" alt="image" src="https://github.com/user-attachments/assets/50ca4dd6-a47f-47b4-aba9-6f1079e85d4a" />


打开后会拉取一个Chrome浏览器，随后自动跳转到学习通页面，可以直接登陆（两种方式皆可），登陆后打开课程页面选择自己想要刷的课就行了

每页最后一个视频播放结束后等待跳转下一页时停顿时间较长，屏幕前紧盯着的小伙伴们需要多等一会哦

每个页面如果视频未播放超过5分钟就会触发自动刷新（播放PPT也算时间哦），在作者的印象里，几乎没有哪个PPT是五分钟放不完的。不过就在近日，作者遇到了一个比较奇葩的老师——他硬生生把一份800多页的PDF给塞进了学习通中，并且成功在播放到600多页的时候触发了五分钟刷新机制。出于显而易见的原因（通过刷新来纠错的机制远比那一两个神奇PPT重要），作者并不想延长触发刷新所需要的时间，因此，如果真的遇到这种特殊情况，还请各位动动你们的小手指，自己过一下这一份“超级”PDF。（相信我，只需要花费你们不超过15秒）

解题的逻辑是额外拉起一个浏览器，使用百度在每一次搜索都会触发的的AI（估计是文心一言）来进行解题，目前只能做选择题（百度几乎是在不登陆前提下的唯一选择），关闭解题功能后会直接跳过测试栏。一页题目做完会自动保存而不是直接提交（万一有的题没解出来自动跳过了呢？），因此在刷完后需要用户自行提交——同时进行检查。由于不可避免地会遭到反爬，因此该功能还不稳定。同时，无头模式过于明显的特征也使得我不得不把两个浏览器页面同时展示在页面上，各位如果有什么好的想法可以和我说。

注：解题功能打开后进行第一次解题时会卡顿较长时间，同时控制台会显示未响应，请稍安勿躁，第一次解题由于需要加载并初始化一些类，因此需要一点时间（这锅得由解题功能开关背）。

最后：如需关闭脚本，可以按下esc键，不要误触了
